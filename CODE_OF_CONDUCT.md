# Code of Conduct

This project welcomes constructive participation from people with different roles, backgrounds, and experience levels.

## Expected behavior

- Be respectful and specific.
- Critique ideas and code, not people.
- Share enough evidence for others to reproduce a technical claim.
- Protect private, customer, tenant, and incident information.
- Accept correction and update inaccurate guidance.
- Keep discussions relevant to the project.

## Unacceptable behavior

Harassment, threats, discrimination, personal attacks, deliberate disclosure of private information, spam, and knowingly unsafe guidance are not accepted.

Project maintainers may edit, remove, or reject contributions that violate these expectations. Serious concerns should be reported privately through the maintainer's GitHub profile rather than argued in a public thread.
